# Quickstart: Pac-Man Web Game

**Branch**: `001-init-web-game`

## Prerequisites

- Node.js 20+ (LTS)
- npm 10+

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Opens the game at `http://localhost:5173`. Hot-module replacement is active — save any file to see changes instantly.

## Testing

```bash
# Unit and integration tests (Jest)
npm test

# Tests with coverage report (must stay ≥80% on src/game/**)
npm run test:coverage

# E2E tests — input latency, load time (Playwright; requires dev server running)
npm run test:e2e
```

## Build

```bash
npm run build
```

Output: `dist/` — a fully static bundle that can be served from any web server or opened via `file://`.

## Project Layout

```
index.html              # Single canvas element + module entry point
src/
  main.js               # Wires GameState, Renderer, InputManager, AudioManager
  game/                 # Pure JS game logic — no DOM/Canvas (fully unit-testable)
  rendering/            # Canvas drawing layer (thin)
  input/                # Keyboard + touch → directional commands
  audio/                # Web Audio API sound effects
  storage/              # localStorage adapter
tests/
  unit/                 # Game logic tests (no browser required)
  integration/          # Player-state interaction tests (jsdom)
  performance/          # Playwright E2E: frame budget, input latency, load time
specs/001-init-web-game/
  spec.md               # Feature requirements
  plan.md               # This implementation plan
  research.md           # Technology decisions
  data-model.md         # Entity schemas and state machines
  contracts/            # Input and storage interface contracts
  tasks.md              # Implementation tasks (generated by /speckit-tasks)
```

## Key Architecture Rule

**Game logic (`src/game/`) has zero imports from `src/rendering/`, `src/input/`, or any browser API.** This is enforced by the project's linting configuration. Violating this rule breaks TDD and is a Constitution violation.
